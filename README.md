# Hermes Mail

Hermes Mail is a private personal assistant that sorts and summarizes email in its owner's Gmail account and, at the owner's request, sends or modifies messages. It has one user and is not offered to the public.

This repository hosts only the public homepage and privacy policy required for the Google OAuth consent screen (Google Auth Platform, External app in production). The application code is not in this repository.

- Homepage: https://samuelboucher.github.io/hermes-mail/
- Privacy policy: https://samuelboucher.github.io/hermes-mail/privacy.html

`index.html` and `privacy.html` are static HTML served by GitHub Pages from the root of the `main` branch. To update the privacy policy, edit `privacy.html` and change its "Last updated" date.

For questions, [open an issue](https://github.com/samuelBoucher/hermes-mail/issues).
